How it works

From a new PR to an automated review in a sequence of serverless steps.

01 — Pull Request event

A developer opens, reopens, or updates a Pull Request. GitHub sends the event payload to the configured webhook endpoint.

02 — Secure ingestion

Amazon API Gateway receives the HTTP request and routes it to the Lambda function. The webhook flow is designed to validate the incoming event and protect credentials.

03 — Diff extraction

Lambda identifies the repository and Pull Request, then retrieves the relevant code diff through the GitHub REST API.

04 — AI analysis

The diff is sent to Google Gemini with a structured review request covering changes, bugs, code quality, security, performance, and improvements.

05 — Review delivery

The generated review is posted back to the Pull Request using GitHub's API, giving developers feedback where the code is already being discussed.

06 — Notification & observability

Amazon SNS can notify stakeholders when reviews complete or fail, while CloudWatch captures execution logs, errors, and monitoring data.
